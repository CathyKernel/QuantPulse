# AlphaForge · US Equity Quant Dashboard

A **fully static, zero-dependency quantitative research dashboard** covering 38 US
mega-cap equities across all 11 GICS sectors with **11.7 years of real daily
market data** (Jan 2015 → Sep 2026, split-adjusted, via Yahoo Finance).

Everything — charting, factor analytics, backtesting and risk statistics — runs
**entirely in your browser**. No server, no build step, no API keys, no tracking.

## Modules

| Tab | What you get |
|-----|--------------|
| **Overview** | Equal-weight universe index, trailing 1Y returns, sector map |
| **Charts** | Interactive candlesticks + volume + moving averages for all 38 names, 6M–3Y ranges, relative strength vs universe |
| **Factors** | 7 classic cross-sectional factors (momentum 12-1 / 6M, 1M reversal, low vol, RSI-14, 52W-high proximity, volume trend) with current cross-sectional ranks, score-vs-return scatter, and 11 years of monthly rank-IC history |
| **Backtest** | Client-side backtesting engine: pick a signal, portfolio size, rebalance frequency and transaction costs — equity curve (log), drawdown, monthly return heatmap, alpha/beta and the current holdings. Runs in <100 ms locally |
| **Risk** | Per-asset vol / Sharpe / max drawdown / VaR 95 / CVaR 95 / beta, a 38×38 correlation heatmap grouped by sector, and a risk-return scatter coloured by drawdown depth |

## Deploy to Netlify (drag & drop)

The bundle is intentionally a plain static site, so Netlify works out of the box:

1. Push this folder to a GitHub repository (or zip it and drag it into
   [app.netlify.com/drop](https://app.netlify.com/drop)).
2. If connecting via Git, Netlify reads `netlify.toml` — leave the build command
   empty and the publish directory as `.` (both are pre-configured).
3. Done. `index.html` sits in the root, so there is no 404 risk.

Any other static host (GitHub Pages, Cloudflare Pages, Vercel) works the same way.

## Run locally

No tooling required:

```bash
# option 1: just open it
open index.html

# option 2: serve it (recommended, avoids any file:// quirks)
python3 -m http.server 8080
# → http://localhost:8080
```

## Project structure

```

├── index.html          # single-page app shell (root = Netlify-safe)
├── netlify.toml        # static hosting config (no build step)
├── css/style.css       # dark glassmorphism theme
└── js/
    ├── data.js         # bundled market data (auto-generated, ~1.7 MB)
    ├── charts.js       # hand-rolled canvas chart engine (zero dependencies)
    └── app.js          # app logic + in-browser backtest & risk engines
```

## Data notes

- Prices are **split-adjusted daily OHLCV** from Yahoo Finance.
- The universe is a static snapshot of 38 large caps — a demonstration panel,
  not a tradable index. Equal-weight statistics are simple arithmetic means.
- Backtests apply costs as `turnover × cost_bps` on each rebalance, assume
  T+0 fills at the close of the rebalance day, and ignore borrow/financing.

## Regenerating the bundle

`data.js` is generated by an offline pipeline (pandas + parquet source).
Replace it with your own payload keeping the same schema — the frontend needs
nothing else.
